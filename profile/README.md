# ReyaanshOS-Reworked

**Linux beyond the desktop.**

ReyaanshOS-Reworked is a Debian-based Linux distribution project inspired by [postmarketOS](https://postmarketos.org/), aiming to bring Linux to PCs, laptops, smartphones, tablets, and more.

### Goals
- Multi-device Linux support
- Debian-based foundation
- Open-source development

**Status:** Early development.
